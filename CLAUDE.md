# ContactCaseStyler — personal hobby project

Solo hobby project, separate from any company work. Owner builds it
with AI help and is still getting hands-on with professional practices.

## What this is

A tiny, no-root Android tweak: restyle every saved contact name in one
tap (`Alex Morgan` → `alexMorgan`, plus many more styles). Backup and
restore included. See [docs/why.md](docs/why.md) first.

## Rules

- **Everything stays inside this folder.** Any doc, skill, or artifact
  for this project lives in this repo — never outside it.
- **Plain, simple language.** No jargon without a plain-words meaning
  next to it. When asked for a TLDR, give only the TLDR.
- **End every finished piece of work with a 2–3 sentence TLDR.**
- **Keep docs current as part of done** — especially
  [docs/status.md](docs/status.md).

Versions ship on the owner saying **"Ship `vX.Y.Z`"** — full pipeline,
zero per-step confirmation. Commit style is `Imp :` / `Fix :` (space
