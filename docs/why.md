# Why

Phone contacts look messy: `PRANVIR singh`, `pranvir  Singh`, `Dr. Pranvir Singh!!`.
Cleaning them one by one is boring, and no dialer restyles them for you.

This tweak applies one consistent style to every saved name in a single
tap — code-style cases for a dev-flavoured identity, plain cases for a
clean look, a Unicode bold for flair. One tap back restores the originals.

Non-goals: editing numbers, syncing anywhere, or touching anything
outside the on-device contacts database.
