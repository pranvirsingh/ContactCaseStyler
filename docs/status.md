# Status

## v0.1.0 — first tweak (this version)

- 9 styles, live preview on real contact names.
- One-tap Backup (on-device JSON) + one-tap Restore.
- Batch apply through the system contacts provider, no root.
- Quick Settings tile + optional Hide-icon switch, so it feels like
  a system tweak rather than an app.
