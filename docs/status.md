# Status

## v0.2.0 — more styles + search safeguard (this version)

- 14 new styles: Swap, Last, First, Initials, Spaced, Dotted, Leet,
  Alternating, Fullwidth, Circled, Fraktur, Script, Strike, Brackets, Stars.
- Every style tagged safe or fun, right in the picker.
- Fun styles auto-save each original name as the contact's nickname,
  so most dialers keep finding styled contacts.
- No real names left anywhere in the app or docs.

## v0.1.0 — first tweak

- 9 styles, live preview on real contact names.
- One-tap Backup (on-device JSON) + one-tap Restore.
- Batch apply through the system contacts provider, no root.
- Quick Settings tile + optional Hide-icon switch, so it feels like
  a system tweak rather than an app.

## Next (not started)

- v0.2.0: per-contact pick (style only selected people).
- v0.3.0: auto-style new contacts as they are saved.
